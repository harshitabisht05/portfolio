# ⚡ Getting Started
- Clone the repository:
  ```bash
  git clone https://github.com/yourusername/portfolio.git
  ```
- Navigate into the project:
  ```bash
  cd portfolio
  ```
- Install dependencies:
  ```bash
  npm install
  ```
- Run development server:
  ```bash
  npm run dev
  ```
- Open in browser: [http://localhost:3000](http://localhost:3000)
